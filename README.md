# Star Wars – The Hangman Game

A Star Wars trivia word-guessing game built entirely in C++


### How to Play?
**Step 1** - Download and move all the files in a separate directory.

**Step 2** - Open Terminal(macOS/Linux) or CommandLine(Windows) and run the following command:

```cmake -S . -B build && cmake --build build && ./build/TheHangman```

### How to use this repo to make your own Hangman Game?

**Step 1** - Open roundPlayer.cpp and add/edit the values of the wordSet vector string on line 13.

**Step 2 (Trivial)** - Open main.cpp and edit the console output statement on line 12 accordingly.
